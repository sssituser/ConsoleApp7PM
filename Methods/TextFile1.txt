Method (function) : It is self contained block of stmts which can be used to
perform a particular task.

Methods are of two types :
	Methods Involved In Steps :
			i .Defining the Methods.
			ii.Consuming the Method or Call Method.
	Observation :
		Every Method Can Take Parameters(inputs):
			int, string, char, void , int[] , float[],boolean
			class...
		Every Method can Give The Results (Return Type):
			string ,int, float, void , int[] , strig[], char,
			class , boolean.

Note : In a class we can have both static methods and non static methods(Instance Methods)
	   i. Static Methods can be Accessed using className.
				or
		  If methods called with Class Name then the method is static method

	   ii. Non Static Methods(Instance Methods) These methods can be accessed using
	   object only.

	   if any method accessed with object then the method non static method or
	   if any method is not able to access using class then the method may be a non static method
